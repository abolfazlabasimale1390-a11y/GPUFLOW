# GPUFlow — Local Lab (Prototype 0.1.0)

**Intelligent AI Workload Routing — early prototype**

این نسخه یک نمونهٔ اولیه برای آزمایش ارتباط دستگاه‌ها و تجربهٔ اولیهٔ مسیریابی است. رابط کاربری واکنش‌گراست و می‌توان آن را از مرورگر کامپیوتر و گوشی باز کرد.

## دو بستهٔ تحویلی

- **GPUFlow-Code-Build.zip**: سورس کامل برای توسعه و بررسی. فایل همراه `gpuflow.runtime` در این بسته وجود ندارد؛ بنابراین برنامه عمداً از این بسته اجرا نمی‌شود.
- **GPUFlow-Execution-Build.zip**: بستهٔ اجرای آزمایشی که فایل `gpuflow.runtime` را دارد و با رمز باز می‌شود. این بسته برای اجرای محلی با Python طراحی شده است.

## رمز آزمایشی

`12435TYIUOP`

این قفل فقط برای تفکیک بستهٔ سورس از بستهٔ اجرا در نمونهٔ اولیه است؛ **سامانهٔ لایسنس حرفه‌ای یا حفاظت ضد مهندسی معکوس نیست**. رمز را در نسخهٔ عمومی یا محصول تجاری استفاده نکن.

## امکانات این نسخه

- رابط داشبورد واکنش‌گرا برای دسکتاپ و موبایل
- ارتباط زندهٔ دو یا چند دستگاه در یک اتاق محلی از طریق WebSocket
- ارسال پیام بین دستگاه‌های متصل
- حضور دستگاه‌ها و فید رویدادهای مشترک
- شبیه‌سازی سبک تصمیم مسیریابی در سه پروفایل Lightweight، Balanced و Advanced
- انتخاب خودکار یا دستی پروفایل آزمایشی

## چیزهایی که هنوز وجود ندارند

- اتصال به API مدل‌های واقعی
- انتخاب یا تخصیص واقعی GPU
- اندازه‌گیری هزینهٔ واقعی، کیفیت پاسخ یا تأخیر مدل
- ذخیره‌سازی دائمی پیام‌ها و حساب کاربری
- استقرار امن عمومی یا مقیاس‌پذیری production

تصمیم‌های Routing در این نسخه با چند قاعدهٔ سادهٔ محلی انجام می‌شوند و صرفاً برای آزمایش رابط و جریان کار هستند؛ نتیجهٔ آن را معیار کیفیت یا صرفه‌جویی واقعی GPUFlow تلقی نکن.

## اجرای بستهٔ آزمایشی در Windows

1. فایل `GPUFlow-Execution-Build.zip` را Extract کن.
2. Python نسخهٔ 3.10 یا جدیدتر را نصب کن و هنگام نصب گزینهٔ **Add Python to PATH** را فعال کن.
3. فایل `start_windows.bat` را اجرا کن.
4. در مرورگر همان کامپیوتر آدرس `http://127.0.0.1:8765` را باز کن.
5. رمز بالا را وارد کن.

بار اول، اسکریپت وابستگی‌های Python را نصب می‌کند؛ بنابراین برای نصب اولیه به اینترنت نیاز است.

## اتصال دو گوشی به کامپیوتر

1. کامپیوتر و هر دو گوشی را به یک شبکهٔ Wi‑Fi متصل کن.
2. سرور را روی کامپیوتر روشن نگه دار.
3. در پنجرهٔ اجرا، IP محلی کامپیوتر چاپ می‌شود؛ اگر مشخص نبود، در Windows دستور `ipconfig` را اجرا و IPv4 Address کارت Wi‑Fi را پیدا کن.
4. روی هر گوشی در مرورگر آدرسی مانند `http://192.168.1.20:8765` را باز کن (به‌جای IP نمونه، IP واقعی کامپیوتر را قرار بده).
5. روی هر سه دستگاه رمز را وارد کن و در بخش **Device bridge** دقیقاً یک نام اتاق یکسان، مثلاً `gpuflow-lab`، بنویس.
6. برای هر دستگاه نام جداگانه انتخاب و **Connect** را بزن. اکنون پیام‌ها و رویدادهای Routing در همان اتاق بین دستگاه‌ها پخش می‌شوند.

اگر Windows Firewall اجازهٔ دسترسی خواست، فقط برای شبکهٔ خصوصی و مورد اعتماد خودت اجازه بده. این سرور را روی اینترنت عمومی یا Wi‑Fi عمومی باز نکن.

## ساخت پوشهٔ اجرایی Windows (.exe)

در پوشهٔ Execution Build فایل `build_windows_exe.bat` را روی خود Windows اجرا کن. این کار PyInstaller را نصب می‌کند و نسخهٔ پوشه‌ای را در `dist\GPUFlow` می‌سازد. فایل `gpuflow.runtime` باید کنار `GPUFlow.exe` باقی بماند؛ اگر حذف یا خراب شود، برنامه بالا نمی‌آید.

این محیط ساخت Linux است؛ بنابراین فایل Windows `.exe` از پیش در این تحویل ساخته نشده است. اسکریپت ساخت Windows همراه بسته است تا exe روی دستگاه Windows ساخته شود.

## امنیت و حریم خصوصی

- برای آزمایش، فقط از شبکهٔ محلی قابل اعتماد استفاده کن.
- این prototype احراز هویت سازمانی، TLS، محدودیت نرخ کامل، دیتابیس یا رمزنگاری سرتاسری ندارد.
- پیام‌ها فقط در حافظهٔ سرور هستند و با خاموش شدن سرور پاک می‌شوند.
- فایل همراه صرفاً یک قفل سادهٔ نمونه است و نباید به‌عنوان حفاظت مالکیت فکری یا مدیریت لایسنس محصول نهایی استفاده شود.
- کلید API یا رمز واقعی سرویس‌ها را به کد اضافه یا در GitHub commit نکن.
